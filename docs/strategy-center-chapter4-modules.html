模块全景与证据等级

七个模块分工明确：B 给出增量的主证据，C 解释增量从哪来，D 把推荐算法和权重的影响划出去，A、E、F 提供事实和管理价值，G 只负责否决。

模块 A覆盖分区与承接

事实底座。回答框架任务覆盖了谁、曝光了谁、承接了多少，以及和人工重叠多少。

问题
框架任务覆盖了谁、曝光了谁、承接了多少；与人工重叠多少。
方法
按周期初的人群包成员关系（资格层）分四个区。用户层互斥；任务层承接同时报去重值。
等级
F
状态
✓ 可以做　P5（结果指标）、P6（任务来源字段）、P7（历史人群包）影响细节

统计与去重规则

  • 用户层互斥：每个用户只属于一个分区，相加不重复。
  • 任务层承接同时报去重值：例如“F 承接 X 万人，H 承接 Y 万人，二者在 Z3 中重叠 Z 万人，去重合计 W 万人”。
  • Z3 不拆分：可以按曝光来源做描述性拆分，但只能标 C。
  • 窗口统一：F 和人工的承接使用相同的 N 日窗口和首次曝光规则。
  • 为什么按资格层分区：曝光由推荐算法决定，并且和用户活跃度高度相关。资格层在分发之前确定，受分发层的污染最少。

模块 B找人增量：多阈值断点

增量主证据。用断点回归（RDD）比较阈值两侧几乎一样的用户：阈值上方被选中，下方没被选中，结果差就是“被选中”的效果。

运行变量
选人分数 − 该子人群阈值（交通用周内分位数）
结果
用户在结果窗口内是否发生目标行为（或笔数、金额），不论有没有被曝光，也就是意向处理效应 ITT
分析单位
子人群 × 周期
等级
阈值处 E1；外推 E1 + 假设；扩大决策 E1；调优功能整体价值 C
状态
✓ 可以做　P1、P2、P3 确认后定稿

计算方法（三步）

1

每个“子人群 × 周期”做一次断点估计

运行变量 = 选人分数 − 阈值；结果看 ITT。K2（未入选者不会被其他子人群选中）保证每个子人群都是一个“干净”的断点。

2

合并估计并分层

带子人群固定效应合并；按“是否同时被人工覆盖”分层；把各阈值处的效应拼成效应-分数曲线；扩大部分在相似度分上单独估计；交通按上周是否入选分层。

3

按“直接证据 + 外推”汇总

只在观测到的阈值范围内沿曲线外推；区间同时反映自助抽样误差和曲线置信带。每月报告外推占比，作为可信度标签。

业务增量 = 初始入选部分 + 扩大新增部分

初始入选部分 = Σ 子人群 Σ 分层 [ 入选人数 × 对应效应 ]
            = 直接证据（带宽内入选用户 × 阈值处效应）       ← E1
            + 外推（带宽外入选用户 × 曲线上的效应）          ← E1 + 外推假设
扩大新增部分 = 同样结构，用相似度分和相似度阈值单独计算       ← E1 + 外推假设

针对实际运营方式，模块 B 还要做五项处理：

① 任务下线（K6）

  • 下线不改变“谁被选中”，只降低入选用户实际得到的干预，所以 ITT 仍然有效。它估的是“在真实运营决策下（包括下线）被选中的效果”，作为主口径。
  • 下线发生在任务或子人群层面，同一子人群内阈值两侧的比较不受影响。
  • 诊断：分别报告“有下线”和“未下线”子人群的效应。只看未下线的子人群会挑出表现好的那些，高估平均效果，只作内部诊断。

② 按效果扩大或缩小人群（K7、K12）

问题处理
主口径怎么分组一律以初始阈值 c₀ 分组，结果窗口覆盖整个周期，衡量策略中心这套自适应流程的真实效果 E1
扩大（相似人群重新打分）单独估计：相似度分的阈值处是新断点（只用生效后的结果），单独外推、单独汇总，不并入初始分数的曲线
扩大把 c₀ 下方的人拉进来c₀ 处变成模糊断点：用“初始是否超过 c₀”作为工具变量、“周期内入选天数”作为实际处理来修正；或直接报告初始部分偏保守。每期报告“c₀ 下方被扩大选中的比例”
缩小（P3）按分数提高阈值：比较的是“继续入选 vs 停止入选”，和主口径不同，只作诊断。按个人前几天表现剔除：依据已受干预影响，不能做断点，只做描述
不能做的事不能用周期内基于新行为重算的分数作为初始人群的运行变量：入选用户的新分数已经受到前几天干预的影响

③ 交通周度产出（K8、K13）

  • 每周一个分析单位，结果窗口 7 天、不跨周；周内 3–5 天的调优照 ② 以周初阈值分组。
  • 分数每周重算、连续入选率高。上周被选中的人因为干预多交易，本周分数更高，所以上周入选状态在本周阈值处一定会跳变。必须按上周入选状态分层；曲线横轴用周内分位数。
  • “上周未入选”层在阈值附近人数少，至少合并 4 周；用入选路径法和校准留出交叉检查。
  • 缴费按月产出，单周期样本较多，跨周期问题较小。

④ 随机桶内的 RDD（诊断）

在 5% 随机桶内单独做一次 RDD，得到“没有推荐算法放大时”的选人效应。和算法桶内的 RDD 对比，可以看出推荐算法对框架任务是放大还是抑制。样本小，只作内部诊断，不计入任何一方的价值。

⑤ 调优决策质量（新增诊断）

指标定义等级
扩大决策的边际增量扩大生效后 c₁ 处的断点效应：> 0 说明扩大值得E1
缩小决策的边际增量c₂ 处“继续入选 vs 停止入选”的效应：≈ 0 或 < 0 说明缩小是对的E1 诊断
下线决策的正确率被下线子人群在下线前的阈值处效应，是否确实低于未下线子人群E2
调优信号与真实增量的一致性调优时用的“效果好坏”信号，和事后估出的增量是否同方向F 对比结果

调优信号的基线（K14、P1）。现在的信号是“该策略针对自身目标，相对基线是否更优”，方向是对的。它能不能反映增量，取决于基线是什么：

建议：调优信号改用（或至少加上）阈值两侧的实时差，它在周期内就能算出来。3–5 天的数据噪声较大，可以先向该子人群的历史效应收缩再用。这样调优优化的目标和管理层考核的“业务增量”是同一个东西。

模块 C组合质量：随机桶内比较

给同一类用户看框架任务还是人工任务，哪个转化更好？用来解释 B 的增量是“组合好”还是“找人准”。

方法
在随机桶内的 Z3 用户中，按“周期内第一次定向曝光是 F 任务还是人工任务”分组（等概率随机，K4），比较结果窗口内的转化。分别和 H1、H2 比较（随机桶内权重不生效，H2 可以直接比）。
定位
解释模块 B 的增量从哪里来，不与模块 B 相加。
限制
结论只代表随机分发条件；测不了人群识别价值（随机桶不改变谁进入人群）。

模块 F预测确定性

让增长可预测、可承诺。按周期自下而上预测，不再从业务目标倒推。

承接预测（每个周期） 
Σ 子人群 ( 入选人数 × 可投放率
          × 曝光率 × 转化率 )

输出 P10/P50/P90。稀疏格子向行业线均值收缩。

增量预测（管理层最关心的“可承诺增量”） 
入选人数 × 模块 B 的历史效应
          （含外推）

模块 B 连续 ≥ 3 个周期稳定后启用；对外承诺用 P25。

  • 调优会改变周期内的策略：预测以初始版本为准，调优的影响在偏差拆解中单列一项。

  • ✓ 可以做　需要 ≥ 3 个周期。

名词解释

按主题分组。可以输入关键词筛选。

业务结构与角色
F / H1 / H2 / H3task source

任务来源。F = 框架策略任务（目标 → Agent 分析 → 选人 → 拆分 → 算法配货 / 渠道）；H1 = 人工经验任务，和 F 最可比；H2 = BI 半自动任务，可能带货品权重；H3 = 人工独有任务（临时活动、BD 合作），不可比，也不应被替代。

子人群sub-segment

框架策略选人的基本单元，每个子人群一个阈值（K2）。分析单位是“子人群 × 周期”。

人群包audience package

任务定向投放的用户列表。框架人群包额外留存候选标识、选人分数、是否入选、子人群 ID。

资格层 / 曝光层

资格层 = 用户是否在某任务的人群包里，分发之前就确定；曝光层 = 用户是否真的看到了任务，受推荐算法影响。分区按资格层划分，以避开分发层的污染。

Z1 / Z2 / Z3 / Z4 覆盖分区

Z1 仅框架覆盖（Z1a 真新覆盖：过去 6 个月没进过人工人群；Z1b 替代覆盖：过去被人工覆盖、本月只有框架）；Z2 仅人工；Z3 共同覆盖；Z4 均未覆盖。用户层互斥。

权重标签boost weight

H2 任务货品上可带的排序加权，会提高曝光和胜出率，所以这两个指标跨来源比较时会被“污染”。随机桶内权重不生效。

调优 / 下线

周期内基于效果的自适应调整：调货品、渠道；效果好就扩大人群，不好就缩小，仍然不好就让任务下线。运营不能删人，但可以下线任务。

相似度分look-alike score

扩大人群时，以当前入选人群为种子，对其他用户计算的相似程度分。它和初始选人分数不在同一条轴上，所以扩大部分单独估计。

结果与口径
业务增量incrementality

在其他一切照常（人工照常投放、推荐算法照常分发、供给不变）的前提下，框架策略选中这批用户带来的额外目标行为。不包含推荐算法价值、自然转化、新供给。

承接 / 承接转化

框架任务首次曝光后 N 日内发生的目标行为（交通暂定 N = 7）。是事实，说明框架任务“参与了”，但不说明“带来了”，不等于增量。

三个口径

增量交易用户（0/1，最稳定，管理层第一口径）、增量交易笔数、增量交易金额（波动最大，同时列补贴成本）。笔数和金额按 P99 截尾。

P99 截尾winsorize

把超过第 99 百分位的极端值压到 P99，降低少数大额用户对均值和方差的影响。

pp（百分点）percentage point

两个百分比之差的单位。转化率从 17% 升到 18.6% 是 +1.6pp，而不是 +1.6%。

证据等级 F / E1 / E2 / C / N/A

事实 / 准实验估算 / 观测估算 / 相关性 / 当前无法可靠计算。只有 F 能给单点数字；E1、E2 必须给区间；C 只说方向。

因果推断方法
断点回归（RDD）Regression Discontinuity Design

当是否接受处理由“分数是否超过阈值”决定时，阈值两侧紧挨着的用户几乎一样，只是一侧被选中、一侧没有。比较两侧结果的跳变，就得到阈值处的因果效应。

运行变量 / 阈值 / 带宽running variable / cutoff / bandwidth

运行变量 = 决定分组的分数（这里是“分数 − 阈值”）；阈值 c₀ 是分界点；带宽是阈值两侧参与比较的分数范围，越窄越可比，但样本越少。

意向处理效应（ITT）Intention-to-Treat

按“是否被分到处理组”比较，不管用户最后有没有真的看到任务。包含了下线、未曝光等真实运营损耗，是管理层要的口径。

模糊断点fuzzy RDD

超过阈值后被处理的概率跳变，但不是从 0 跳到 1。例如扩大把 c₀ 下方的人也拉进来了。需要用工具变量修正，否则直接比较会低估效应。

工具变量instrumental variable

一个只通过“处理”影响结果的变量。这里用“初始是否超过 c₀”作为工具，“周期内入选天数”作为实际处理强度，估计每单位处理的效应。

固定效应fixed effects

合并多个子人群估计时，给每个子人群一个独立截距，吸收子人群之间的基础差异，只用子人群内部阈值两侧的比较来估效应。

效应-分数曲线 / 外推

不同阈值落在不同分数上，每个阈值给出一个“该分数处的边际效应”，连成曲线。外推 = 用曲线估计远离阈值的入选用户效应，依赖“效应随分数平滑变化”的假设（A4）。

周内分位数

分数在当周候选用户中的百分位。交通每周重算分数，原始分数尺度可能漂移，所以曲线横轴改用分位数。

遗留效应carry-over

本周入选对下周交易的影响。周度结果窗口看不到它，所以按周累加的月度增量偏保守。

入选路径法

以用户第一次入选的那一周为起点，比较该周阈值两侧用户在随后 4 周内的总结果，估“进入周度投放流”的完整效果（含连续入选和遗留效应）。它应不低于周度分层累加的结果。

校准留出calibration holdout

定期（例如交通每月 1 周）在每个子人群内按分数分位随机留出 5% 入选用户，不下发框架任务，直接测总增量，用来校准 RDD 的外推曲线。

匹配 / 双重差分（DiD）matching / difference-in-differences

观测数据上的估计方法，存在未观测混杂，等级为 E2。框架里作为 RDD 的三角互证。

分发与实验
算法桶 / 随机桶

按 user_id hash 分流。随机桶占 5%，只在用户所属人群的任务中等概率随机分发，权重不生效；其余为算法桶，由推荐算法召回和排序。

hash 分流

用 user_id 的哈希值决定分桶。结果稳定、与用户行为无关（假设 A8），可以用 A/A 检验验证。

A/A 检验

在两组本应没有差别的时期（例如分发策略上线前）比较指标，确认分组本身是平衡的。

调优信号的基线

判断“效果好坏”时用来对比的参照。只有“未被选中的相似用户”这类基线接近增量；用大盘平均会系统性偏向扩大。

胜出率 / 挤出

胜出率 = 任务进入候选后最终被曝光的比例；挤出 = 框架任务胜出导致其他任务（尤其是 H3）失去曝光。判断挤出看用户层总结果，不看任务层承接之和。

统计与预测
自助抽样bootstrap

从样本中有放回地反复抽样、重算估计值，用估计值的分布得到置信区间。

P10 / P25 / P50 / P90

预测分布的分位数。P50 为中位预测；[P10, P90] 为 80% 区间；对外承诺建议用 P25（较保守）。

收缩（经验贝叶斯）shrinkage

样本少的估计值向更大群体的均值（行业线均值、子人群历史效应）拉近，降低噪声。例如用 Beta 先验处理稀疏的转化率格子。

连环替代法

按固定顺序依次把预测因子替换成实际值，每一步的变化就是该因子造成的偏差，所以总偏差可以拆成几段。

WAPEWeighted Absolute Percentage Error

Σ|实际 − P50| ÷ Σ实际，衡量预测误差；初期参考 ≤ 15%。

统计功效 / MDEminimum detectable effect

在给定样本量下能可靠检测到的最小差异。用 tools/power_calc.py 计算；虚构量级下 RDD 单周期约 0.6pp。

HHIHerfindahl–Hirschman Index

集中度指数 = 各货品曝光份额的平方和。越接近 1 越集中，过度集中可能挤压其他供给。

安慰剂检验 / 密度检验

安慰剂：在不该有效应的地方（上线前周期、假阈值）套用 RDD，结果应为 0。密度检验：阈值两侧人数分布应连续，有跳变说明可能有人“挤过”阈值。
